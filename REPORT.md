## Найденные ошибки и исправления

### Предметы и полиморфизм
| Ошибка | Причина | Исправление | Проверка |
|--------|---------|-------------|----------|
| Отрицательное количество в `Item` не обнулялось | В конструкторе и `setQuantity` не было проверки на `< 0` | Добавил `quantity < 0 ? 0 : quantity` | Тест "negative quantity becomes 0" |
| `Item::use()` не виртуальный | Метод объявлен без `virtual` | Добавил `virtual` в `Item`, `override` в наследниках | Тест "virtual dispatch weapon" |
| `Potion::use()` увеличивал количество | Опечатка `++quantity_` | Заменил на `--quantity_`, добавил проверку на 0 | Тесты "potion drink use", "potion empty use" |
| Отрицательный урон/защита/лечение не обнулялись | Не было проверок в конструкторах `Weapon`, `Armor`, `Potion` | Добавил проверки `< 0 ? 0 : ...` | Тесты "negative damage/defense/healing" |

### Инвентарь
| Ошибка | Причина | Исправление | Проверка |
|--------|---------|-------------|----------|
| `add` возвращал `true` для `nullptr` | Не было проверки на нулевой указатель | Добавил `if (item == nullptr) return false;` | Тест "add nullptr" |
| `add` возвращал `true` для дубликата адреса | Не было проверки на повторный адрес | Добавил цикл сравнения адресов | Тест "add duplicate address" |
| `size` возвращал `items_.size() + 1` | Опечатка | Убрал `+ 1` | Тесты "empty size", "one object" |
| `find` искал неподходящий предмет | Сравнение `!=` вместо `==` | Заменил на `==` | Тест "find returns first matching" |
| `remove` удалял последний элемент | Использовался `pop_back()` | Заменил на `erase(items_.begin() + index)` | Тесты "remove first/middle/last" |
| `clear` был пустой | Не было реализации | Добавил `items_.clear();` | Тест "clear empties inventory" |
