# Отчет по заданию "Сломанный инвентарь"

**ФИО:** Ролинская Диана
**Группа:** [24/2]

## Ошибка → Причина → Исправление → Проверка

1. **Отрицательные значения характеристик**
   - *Причина:* В конструкторах и сеттерах не было проверок на отрицательные числа.
   - *Исправление:* Добавлено тернарное условие `(value < 0 ? 0 : value)`.
   - *Проверка:* Тест `negative damage becomes zero`.

2. **Отсутствие полиморфизма (use)**
   - *Причина:* В базовом классе `Item` метод `use()` не был помечен как `virtual`.
   - *Исправление:* Добавлено слово `virtual` в `Item` и `override` в наследниках.
   - *Проверка:* Тест `virtual dispatch weapon`.

3. **Логика зелья (Potion)**
   - *Причина:* Зелье увеличивало количество (`++`) вместо уменьшения, а при нуле возвращало "Drink" вместо "Empty".
   - *Исправление:* Заменено на `--quantity_`, добавлена проверка на 0.
   - *Проверка:* Блок тестов на `potion`.

4. **Метод Inventory::add**
   - *Причина:* Возвращал `true` даже при добавлении `nullptr` или дубликата.
   - *Исправление:* Добавлены проверки, возвращается `false` при ошибке.
   - *Проверка:* Тесты `add nullptr rejected` и `add duplicate address rejected`.

5. **Метод Inventory::size**
   - *Причина:* Возвращал размер вектора + 1.
   - *Исправление:* Убран `+ 1`.
   - *Проверка:* Тесты `empty size`, `one object`.

6. **Метод Inventory::find**
   - *Причина:* Логика была инвертирована (`!=` вместо `==`).
   - *Исправление:* Изменено на `==`.
   - *Проверка:* Тест `find sword`.

7. **Метод Inventory::remove**
   - *Причина:* Использовался `pop_back()`, удаляющий последний элемент, вместо указанного индекса.
   - *Исправление:* Использован `erase(items_.begin() + index)`.
   - *Проверка:* Тест на удаление среднего элемента.

8. **Метод Inventory::clear**
   - *Причина:* Метод был пустым.
   - *Исправление:* Добавлен `items_.clear()`.
   - *Проверка:* Тест `clear inventory`.
